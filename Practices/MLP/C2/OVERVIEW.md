# 딥러닝

| 키워드 | 설명 |
|--------|------|
| 딥러닝 (Deep Learning) | 인공 신경망을 기반으로 한 기계 학습의 한 분야로, 대량의 데이터에서 패턴을 학습합니다. |
| 뉴런 (Neuron)	| 신경망의 기본 단위로, 입력 신호를 받아 처리하고 출력 신호를 생성합니다. |
| 인공 뉴런 (Artificial Neuron) | 생물학적 뉴런을 모방하여 설계된 수학적 모델로, 입력과 가중치를 기반으로 활성화 함수를 통해 출력을 생성합니다. |
| 순전파 (Forward Propagation) | 입력 데이터가 신경망을 통해 출력으로 전달되는 과정입니다. |
| 신경망 (Neural Network) | 여러 개의 인공 뉴런이 연결되어 구성된 모델로, 입력과 출력을 연결하여 학습합니다. |
| 인공 신경망 (Artificial Neural Network) | 인공 뉴런으로 구성된 신경망으로, 다양한 문제를 해결하는 데 사용됩니다. |

# 딥러닝 기초

| 키워드 | 설명 |
|--------|------|
| 기울기 하강 (Gradient Descent) | 비용 함수를 최소화하기 위해 가중치를 업데이트하는 최적화 알고리즘입니다. |
| 비용 함수 (Cost Function) | 모델의 예측값과 실제값 간의 차이를 측정하는 함수로, 모델의 성능을 평가합니다. |
| 학습률 (Learning Rate) | 가중치 업데이트 시 얼마나 큰 변화를 줄지를 결정하는 하이퍼파라미터입니다. |
| 역전파 (Backpropagation) | 출력에서 입력 방향으로 오차를 전파하여 가중치를 업데이트하는 알고리즘입니다. |
| 기울기 소실 문제 (Vanishing Gradient Problem) | 깊은 신경망에서 역전파 시 기울기가 매우 작아져 학습이 어려워지는 문제입니다. |
| 활성화 함수 (Activation Function) | 뉴런의 출력을 결정하는 함수로, 비선형성을 추가하여 신경망의 표현력을 높입니다. |

# Keras 모델링

| 키워드 | 설명 |
|--------|------|
| 딥 러닝 라이브러리 (Deep Learning Library) | 딥러닝 모델을 구축하고 훈련하는 데 사용되는 소프트웨어 라이브러리입니다. |
| Keras를 사용한 회귀 모델 (Regression Model with Keras) | Keras 라이브러리를 사용하여 연속적인 값을 예측하는 모델을 구축하는 방법입니다. |
| Keras를 사용한 분류 모델 (Classification Model with Keras) | Keras 라이브러리를 사용하여 데이터를 미리 정의된 클래스에 분류하는 모델을 구축하는 방법입니다. |

# 지도 신경망과 비지도 신경망

| 키워드 | 설명 |
|--------|------|
| 지도 신경망과 비지도 신경망 (Supervised and Unsupervised Neural Networks) | 지도 신경망은 레이블이 있는 데이터로 학습하고, 비지도 신경망은 레이블이 없는 데이터로 학습합니다. |
| 얕은 신경망과 깊은 신경망 (Shallow and Deep Neural Networks) | 얕은 신경망은 적은 수의 층으로 구성되고, 깊은 신경망은 많은 층으로 구성되어 복잡한 패턴을 학습합니다. |
| 컨볼루션 신경망 (Convolutional Neural Network) | 이미지 처리에 특화된 신경망으로, 합성곱 층을 사용하여 특징을 추출합니다. |
| 순환 신경망 (Recurrent Neural Network) | 시퀀스 데이터를 처리하는 데 적합한 신경망으로, 이전 출력을 다음 입력으로 사용하는 구조입니다. |
| 트랜스포머 (Transformer) | 자연어 처리에 주로 사용되는 모델로, 자기 주의 메커니즘을 통해 입력 시퀀스의 관계를 학습합니다. |
| 오토인코더 (Autoencoder) | 입력 데이터를 압축하고 복원하는 비지도 학습 모델로, 데이터의 특징을 학습합니다. |
| 제한 볼츠만 기계 (Restricted Boltzmann Machine) | 비지도 학습 모델로, 데이터의 분포를 학습하여 특징을 추출합니다. |
| 사전 훈련된 모델 (Pre-trained Model) | 대규모 데이터셋에서 미리 학습된 모델로, 새로운 작업에 활용할 수 있는 특징을 제공합니다. |
