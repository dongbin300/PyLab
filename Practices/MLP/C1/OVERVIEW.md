# 선형 및 로지스틱 회귀

| 키워드 | 설명 |
|--------|------|
| 단일 선형 회귀 (Simple Linear Regression) | 하나의 독립 변수를 사용하여 종속 변수를 예측하는 회귀 분석 기법입니다. 예를 들어, 광고비에 따른 판매량 예측이 있습니다. |
| 다중 선형 회귀 (Multiple Linear Regression) |	두 개 이상의 독립 변수를 사용하여 종속 변수를 예측하는 회귀 분석 기법입니다. 여러 요인이 결과에 미치는 영향을 동시에 고려할 수 있습니다. 예를 들어, 주택 가격을 예측할 때 면적, 위치, 방 개수 등을 함께 고려합니다. |
| 로지스틱 회귀 (Logistic Regression) | 종속 변수가 이진형(예: 0 또는 1)일 때 사용되는 회귀 분석 기법입니다. 확률을 기반으로 클래스를 예측하며, 주로 분류 문제에 사용됩니다. 예를 들어, 고객이 제품을 구매할 확률을 예측하는 데 사용됩니다. |

# 지도 학습 모델

| 키워드 | 설명 |
|--------|------|
| 분류 (Classification) | 주어진 데이터 포인트를 미리 정의된 클래스 중 하나로 분류하는 작업입니다. 예를 들어, 이메일을 스팸과 비스팸으로 분류하는 것이 있습니다. |
| 의사결정트리 (Decision Tree) | 데이터를 분할하여 결정 규칙을 생성하는 트리 구조의 모델입니다. 각 노드는 특정 특성에 대한 질문을 나타내며, 리프 노드는 최종 결정을 나타냅니다. |
| 회귀트리 (Regression Tree) | 연속적인 값을 예측하기 위해 데이터를 분할하는 트리 구조입니다. 각 리프 노드는 특정 값의 평균을 나타내며, 예를 들어 주택 가격 예측에 사용될 수 있습니다. |
| 서포트 벡터 머신 (SVM) | 데이터 포인트를 분리하는 최적의 경계를 찾는 모델입니다. 고차원 공간에서 데이터를 분리하는 초평면을 사용하여 분류를 수행합니다. |
| K-최근접 이웃 (KNN) | 새로운 데이터 포인트의 클래스를 결정하기 위해 가장 가까운 K개의 이웃을 참조하는 비모수적 모델입니다. 거리 기반으로 작동하며, K의 값에 따라 결과가 달라질 수 있습니다. |
| 바이어스 (Bias) | 모델이 학습 데이터의 패턴을 잘 포착하지 못할 때 발생하는 오류입니다. 높은 바이어스는 과소적합을 초래할 수 있습니다. |
| 분산 (Variance) | 모델이 학습 데이터에 너무 민감하게 반응할 때 발생하는 오류입니다. 높은 분산은 과적합을 초래할 수 있습니다. |
| 앙상블 모델 (Ensemble Model) | 여러 개의 모델을 결합하여 더 나은 예측 성능을 얻는 방법입니다. 대표적인 방법으로는 배깅(Bagging)과 부스팅(Boosting)이 있습니다. |

# 비지도 학습 모델

| 키워드 | 설명 |
|--------|------|
| K-평균 (K-Means) | 데이터를 K개의 클러스터로 나누는 비지도 학습 알고리즘입니다. 각 클러스터의 중심을 기준으로 데이터를 할당하며, 클러스터의 수 K는 사전에 정의해야 합니다. |
| DBSCAN (Density-Based Spatial Clustering of Applications with Noise) | 밀도 기반 클러스터링 알고리즘으로, 데이터 포인트의 밀도를 기준으로 클러스터를 형성합니다. 노이즈 데이터도 효과적으로 처리할 수 있습니다. |
| HDBSCAN (Hierarchical DBSCAN) | DBSCAN의 확장 버전으로, 클러스터의 계층 구조를 생성합니다. 다양한 밀도에서 클러스터를 탐지할 수 있어 더 유연한 클러스터링을 제공합니다. |
| 클러스터링 (Clustering) | 비슷한 특성을 가진 데이터 포인트를 그룹화하는 과정입니다. 데이터의 구조를 이해하고 패턴을 발견하는 데 유용합니다. |
| 차원축소 (Dimensionality Reduction) | 고차원 데이터를 저차원으로 변환하여 데이터의 복잡성을 줄이는 기법입니다. 데이터 시각화 및 처리 속도 향상에 도움을 줍니다. |
| 피처 엔지니어링 (Feature Engineering) | 모델 성능을 향상시키기 위해 원본 데이터에서 새로운 특성을 생성하는 과정입니다. 데이터의 의미를 더 잘 반영할 수 있도록 합니다. |
| PCA (Principal Component Analysis) | 선형 차원 축소 기법으로, 데이터의 분산을 최대화하는 새로운 축을 찾아 데이터를 변환합니다. 주요 성분을 통해 데이터의 구조를 이해할 수 있습니다. |
| T-SNE (T-Distributed Stochastic Neighbor Embedding) | 비선형 차원 축소 기법으로, 고차원 데이터를 저차원으로 변환하여 데이터 포인트 간의 유사성을 보존합니다. 주로 데이터 시각화에 사용됩니다. |
| UMAP (Uniform Manifold Approximation and Projection) | 비선형 차원 축소 기법으로, 데이터의 전역 구조와 지역 구조를 모두 보존하며, 빠른 속도로 차원 축소를 수행합니다. |

# 모델 평가 및 검증

| 키워드 | 설명 |
|--------|------|
| 회귀 모델 평가 (Regression Model Evaluation) | 회귀 모델의 성능을 평가하기 위해 평균 제곱 오차(MSE), 평균 절대 오차(MAE), 결정 계수(R-squared) 등을 사용합니다. 예측값과 실제값의 차이를 기반으로 모델의 정확성을 판단합니다. |
| 지도 학습 모델 평가 (Supervised Learning Model Evaluation) | 정확도(Accuracy), 정밀도(Precision), 재현율(Recall), F1 Score 등의 지표를 사용하여 모델이 데이터를 얼마나 잘 분류하는지 평가합니다. 특히 불균형 데이터셋에서 중요합니다. |
| 비지도 학습 모델 평가 (Unsupervised Learning Model Evaluation) | 실루엣 점수(Silhouette Score), Davies-Bouldin Index, 클러스터 내/간 거리 등을 활용하여 클러스터링 품질과 데이터 포인트 간 유사성을 평가합니다. |
| 모델 검증 (Model Validation) | 모델의 일반화 성능을 확인하기 위해 훈련 데이터와 테스트 데이터를 분리하여 검증합니다. 교차 검증(Cross-Validation)을 통해 보다 신뢰성 있는 평가가 가능합니다. |
| 회귀 정규화 (Regression Regularization) | 과적합을 방지하기 위한 기법으로, L1 정규화(라쏘 회귀)와 L2 정규화(릿지 회귀)가 대표적입니다. 모델의 가중치를 조정하여 모델 복잡도를 줄입니다. |
| 데이터 유출 (Data Leakage) | 모델 학습 시 미래 정보가 포함되어 실제 환경에서 성능이 저하되는 문제입니다. 이를 방지하려면 훈련 데이터와 테스트 데이터를 철저히 분리하고 올바른 피처 엔지니어링을 수행해야 합니다. |
