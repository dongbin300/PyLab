# Keras API

| 키워드 | 설명 |
|-|-|
| Keras Functional API | Keras에서 모델을 정의하는 방법 중 하나로, 복잡한 모델 구조를 쉽게 구성할 수 있도록 해줍니다. |
| Keras Subclassing API | Keras에서 사용자 정의 모델을 만들기 위한 방법으로, tf.keras.Model 클래스를 상속받아 모델의 구조와 동작을 자유롭게 정의할 수 있습니다. |
| 커스텀 레이어 (Custom Layer) | Keras에서 제공하는 기본 레이어 외에 사용자가 직접 정의한 레이어로, 특정 기능이나 연산을 수행하도록 설계됩니다. |

# CNN

| 키워드 | 설명 |
|-|-|
| VGG | 이미지 분류를 위한 딥러닝 모델로, 여러 개의 컨볼루션 레이어와 풀링 레이어로 구성되어 있으며, 깊은 구조를 통해 높은 성능을 보여줍니다. |
| ResNet | 잔차 학습(Residual Learning) 개념을 도입한 딥러닝 모델로, 매우 깊은 신경망을 효과적으로 학습할 수 있도록 해줍니다. |
| 데이터 증강 (Data Augmentation) | 훈련 데이터의 양을 늘리기 위해 원본 데이터를 변형하여 새로운 데이터를 생성하는 기법입니다. |
| 커스텀 증강 (Custom Augmentation) | 사용자가 정의한 특정 방법으로 데이터를 변형하여 데이터 증강을 수행하는 기법입니다. |
| 사전 훈련된 모델 (Pre-trained Model) | 대규모 데이터셋에서 미리 학습된 모델로, 특정 작업에 대해 재사용할 수 있는 모델입니다. |
| Transpose Convolution | 업샘플링을 수행하는 레이어로, 입력 텐서를 더 큰 출력 텐서로 변환합니다. 주로 이미지 생성 모델에서 사용됩니다. |

# 트랜스포머

| 키워드 | 설명 |
|-|-|
| 자기 주의 메커니즘 (Self-Attention Mechanism) | 입력 데이터의 각 요소가 서로에게 주의를 기울일 수 있도록 하는 메커니즘으로, 주로 자연어 처리와 이미지 처리에서 사용됩니다. |
| 피드포워드 신경망 (Feedforward Neural Network) | 입력 데이터가 한 방향으로만 흐르는 신경망으로, 순환 구조가 없는 모델입니다. |
| 인코더 레이어 (Encoder Layer) | 입력 데이터를 압축하여 잠재 공간으로 변환하는 레이어로, 주로 오토인코더와 같은 모델에서 사용됩니다. |
| 디코더 레이어 (Decoder Layer) | 인코더에서 변환된 잠재 공간을 원래의 데이터 형태로 복원하는 레이어입니다. |
| 순차 데이터 (Sequential Data) | 시간에 따라 순서가 있는 데이터로, 주로 시계열 데이터나 자연어 처리에서 다루어집니다. |
| 클러스터링 (Clustering) | 데이터 포인트를 유사성에 따라 그룹화하는 비지도 학습 기법입니다. |
| 연관 분석 (Association Analysis) | 데이터 간의 관계를 찾는 기법으로, 주로 장바구니 분석에 사용됩니다. |

# 비지도 학습과 생성 모델

| 키워드 | 설명 |
|-|-|
| 오토인코더 (Autoencoder) | 입력 데이터를 압축하고 복원하는 신경망 구조로, 주로 데이터 차원 축소와 노이즈 제거에 사용됩니다. |
| GAN (Generative Adversarial Network) | 두 개의 신경망(생성자와 판별자)이 서로 경쟁하며 학습하는 구조로, 새로운 데이터를 생성하는 데 사용됩니다. |
| 확산 모델 (Diffusion Model) | 데이터의 분포를 모델링하여 새로운 샘플을 생성하는 기법으로, 최근에 주목받고 있습니다. |

# 심화 Keras

| 키워드 | 설명 |
|-|-|
| 커스텀 훈련 루프 (Custom Training Loop) | Keras의 기본 훈련 루프 대신 사용자가 정의한 훈련 과정을 구현하는 방법입니다. |
| 하이퍼파라미터 튜닝 (Hyperparameter Tuning) | 모델의 성능을 최적화하기 위해 하이퍼파라미터를 조정하는 과정입니다. |
| 랜덤 서치 튜너 (Random Search Tuner) | 하이퍼파라미터 튜닝 방법 중 하나로, 무작위로 하이퍼파라미터 조합을 선택하여 최적의 조합을 찾습니다. |
| 모델 최적화 (Model Optimization) | 모델의 성능을 향상시키기 위해 다양한 기법을 적용하는 과정입니다. |
| 지식 증류 (Knowledge Distillation) | 큰 모델에서 학습한 지식을 작은 모델로 전이하여 성능을 향상시키는 기법입니다. |

# 강화 학습

| 키워드 | 설명 |
|-|-|
| 강화 학습 (Reinforcement Learning) | 에이전트가 환경과 상호작용하며 보상을 최대화하는 방향으로 학습하는 기법입니다. |
| Q-learning | 강화 학습의 한 방법으로, 에이전트가 최적의 행동을 선택하기 위해 Q-값을 업데이트하는 알고리즘입니다. |
| Q-Network | Q-learning을 신경망으로 구현한 모델로, 상태-행동 쌍에 대한 Q-값을 예측합니다. |
| Q-Value | 특정 상태에서 특정 행동을 선택했을 때 예상되는 보상의 총합을 나타내는 값입니다. |
| DQN (Deep Q-Network) | Q-learning을 심층 신경망과 결합하여 복잡한 환경에서도 학습할 수 있도록 한 알고리즘입니다. |
