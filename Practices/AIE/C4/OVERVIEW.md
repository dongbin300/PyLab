|키워드|설명|
|-|-|
|텐서 (Tensor)|다차원 배열로, 딥러닝에서 데이터의 입력, 출력 및 가중치를 표현하는 기본 구조입니다.|
|Torch Vision|PyTorch의 비전 관련 라이브러리로, 이미지 처리 및 컴퓨터 비전 작업을 위한 다양한 도구와 데이터셋을 제공합니다.|
|Forward step|신경망에서 입력 데이터를 통해 출력을 계산하는 과정으로, 모델의 예측을 생성합니다.|
|비용 표면 (Cost Surface)|모델의 손실 함수 값을 시각화한 것으로, 매개변수의 조합에 따른 손실의 변화를 나타냅니다.|
|등고선 (Contour)|비용 표면에서 손실 값이 동일한 지점을 연결한 선으로, 최적화 과정에서 경로를 이해하는 데 도움을 줍니다.|
|Y hat|모델이 예측한 출력값을 나타내며, 실제 값 Y와 비교하여 모델의 성능을 평가하는 데 사용됩니다.|
|Epoch|전체 훈련 데이터셋을 한 번 학습하는 과정을 의미하며, 여러 Epoch를 통해 모델의 성능을 향상시킵니다.|
|SGD (Stochastic Gradient Descent)|확률적 경량 경량 하강법으로, 매개변수를 업데이트하기 위해 무작위로 선택된 데이터 샘플을 사용하는 최적화 알고리즘입니다.|
|데이터 로더 (Data Loader)|훈련 데이터셋을 배치 단위로 로드하고 전처리하는 도구로, 모델 훈련 시 효율성을 높입니다.|
|MBGD (Mini-Batch Gradient Descent)|미니 배치 경량 하강법으로, 전체 데이터셋을 작은 배치로 나누어 경량 하강법을 수행하여 학습 속도를 높입니다.|
|Optimizer|모델의 가중치를 업데이트하는 알고리즘으로, 손실 함수를 최소화하기 위해 사용됩니다.|
|다중 출력 선형 회귀 (Multi-output Linear Regression)|여러 개의 출력 변수를 예측하는 선형 회귀 모델로, 각 출력에 대해 독립적인 회귀 계수를 학습합니다.|
|베르누이 분포 (Bernoulli Distribution)|두 가지 가능한 결과(예: 성공/실패)를 가지는 확률 분포로, 이진 분류 문제에서 자주 사용됩니다.|
|우도 (Likelihood)|주어진 데이터가 특정 모델에 의해 생성될 확률을 나타내며, 모델의 적합도를 평가하는 데 사용됩니다.|
|교차 엔트로피 (Cross Entropy)|두 확률 분포 간의 차이를 측정하는 손실 함수로, 주로 분류 문제에서 사용되며, 모델의 예측과 실제 레이블 간의 차이를 최소화합니다.|
