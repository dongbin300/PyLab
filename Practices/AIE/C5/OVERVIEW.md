| 키워드 | 설명 |
|-|-|
| Softmax | 다중 클래스 분류에서 각 클래스의 확률을 계산하는 함수입니다. |
| Argmax | 주어진 함수의 최대값을 가지는 입력값을 반환하는 함수입니다. |
| Deep Neural Network | 여러 개의 은닉층을 가진 인공 신경망으로, 복잡한 패턴을 학습할 수 있습니다. |
| 결정 함수 (Decision Function) | 주어진 입력에 대해 특정 클래스를 예측하는 함수입니다. |
| Dropout | 신경망의 과적합을 방지하기 위해 무작위로 뉴런을 드롭하는 기법입니다. |
| 베르누이 확률 변수 (Bernoulli Random Variable) | 두 가지 결과 중 하나를 가질 수 있는 확률 변수입니다. |
| Xavier 초기화 (Xavier Initialization) | 신경망의 가중치를 입력과 출력의 수에 따라 초기화하는 방법입니다. |
| He 초기화 (He Initialization) | ReLU 활성화 함수를 사용하는 신경망의 가중치를 초기화하는 방법입니다. |
| 모멘텀 (Momentum) | 기계 학습에서 최적화 알고리즘의 일종으로, 경량화된 학습을 위해 사용됩니다. |
| 배치 정규화 (Batch Normalization) | 각 층의 입력을 정규화하여 학습 속도와 안정성을 높이는 기법입니다. |
| 미니 배치 (Mini-batch) | 전체 데이터셋을 작은 배치로 나누어 학습하는 방법입니다. |
| 시프트 파라미터 (Shift Parameter) | 신경망의 각 층에서 입력을 조정하는 추가적인 파라미터입니다. |
| 내부 공변량 변화 (Internal Covariate Shift) | 신경망의 각 층에서 입력 분포가 변화하는 현상입니다. |
| 컨볼루션 (Convolution) | 필터를 사용하여 입력 이미지의 특징을 추출하는 연산입니다. |
| 스트라이드 (Stride) | 컨볼루션 연산에서 필터가 입력 이미지 위를 이동하는 간격을 의미합니다. |
| 제로 패딩 (Zero Padding) | 입력 이미지의 가장자리에 0을 추가하여 출력 크기를 조정하는 방법입니다. |
| 맥스 풀링 (Max Pooling) | 입력의 특정 영역에서 최대값을 선택하여 출력하는 다운샘플링 기법입니다. |
